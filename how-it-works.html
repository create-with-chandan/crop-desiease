HOW THE SYSTEM WORKS

From image to AI insight.

CropAI sends an uploaded plant image to its Flask API, where image processing and a configured TensorFlow model power a four-stage analysis pipeline.

01

Capture

Choose a JPG or PNG image in the scanner. CropAI sends it to the Flask API for analysis; uploads are limited to 8 MB.

02

Pre-process

The scanner validates and decodes the image in your browser, checks for visible plant material, then resizes and normalizes it for the model.

03

Detect

A configured TensorFlow model scores the image against its trained classes. Low-confidence results are rejected.

04

Explain

The scanner displays the predicted class, confidence and available guidance. Treat predictions as screening, not a diagnosis.

TECH STACK

The intelligence behind CropAI.

The scanner frontend uploads images to the Flask API. The API preprocesses them and runs inference when trained model artifacts are configured.

AI

Machine Learning

The classifier learns disease-related visual patterns from labeled images and rejects predictions below its confidence threshold.

CV

Computer Vision

OpenCV decodes and resizes uploads, normalizes image input, and screens for obvious non-plant images before inference.

TF

TensorFlow

TensorFlow and Keras train and load the neural-network image classifier used by the prediction API.

PY

Python

Python powers dataset preparation, model training and the optional Flask API; TensorFlow.js runs the exported model directly in the browser.

FL

Flask

Flask serves the frontend and provides `/api/health` and `/api/predict` endpoints for model status and image analysis.

JS

Frontend

HTML, CSS and JavaScript provide image upload, preview, API requests, and readable prediction results.

THE PIPELINE

Image → Processing → Model → Prediction

The scanner sends an image to the Flask API, which validates and preprocesses it before running model inference. A fresh checkout needs trained model and label files before predictions are available.
